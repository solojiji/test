# مركز ركن خيرات — Next.js + MySQL

متجر عربي باتجاه RTL، بالأبيض والأسود والأخضر، مع لوحة إدارة وطلب عبر واتساب.
رقم المحل مضبوط على 9647770445030، ويمكن تغييره من إعدادات الإدارة.

## تشغيل كامل باستخدام Docker

1. انسخ `.env.example` إلى `.env`.
2. استبدل كلمات المرور الثلاث بكلمات مختلفة وقوية. كلمة مرور الإدارة لا تقل عن 12 حرفاً، وهي كلمة دخول `/admin`.
3. شغّل:

```bash
docker compose up -d --build
```

افتح `http://localhost:3000`، ولوحة الإدارة `http://localhost:3000/admin`.
تُنشأ الجداول تلقائياً عند أول طلب API. قاعدة البيانات فارغة من المنتجات التجريبية: أضف الأقسام ثم المنتجات من لوحة الإدارة.
Docker يحفظ MySQL والصور في volumes مستقلة. لا تحذفها عند تحديث المشروع.

## تشغيل دون Docker

يتطلب Node.js 20.9+ وMySQL 8.0+.
أنشئ قاعدة `rukn_khairat` ومستخدم MySQL لديه صلاحيات عليها. اضبط متغيرات البيئة:

```text
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=rukn_khairat
DB_USER=rukn
DB_PASSWORD=YOUR_DATABASE_PASSWORD
ADMIN_PASSWORD=YOUR_UNIQUE_ADMIN_PASSWORD
PUBLIC_ORIGIN=http://localhost:3000
COOKIE_SECURE=false
```

ضعها في `.env.local` ثم:

```bash
npm ci
npm run build
npm start
```

للتطوير: `npm run dev`.
الصور تحفظ داخل `uploads/`، لذا يلزم قرص دائم وصلاحيات كتابة للمجلد.

## الاستضافة الفعلية

استخدم استضافة تدعم Next.js بخادم Node.js وMySQL وقرص دائم للصور، أو Docker على VPS. لا تكفي استضافة HTML ثابتة لتشغيل قاعدة البيانات ولوحة الإدارة.
ضع الموقع وراء HTTPS، واضبط `PUBLIC_ORIGIN` إلى رابط موقعك و`COOKIE_SECURE=true`.
إذا كان reverse proxy يحذف ويعيد ضبط `X-Forwarded-For` إلى عنوان الزائر الموثوق، يمكن ضبط `TRUST_PROXY=true` لحدود المحاولات حسب عنوان الزائر. لا تفعله خلف proxy يسمح للزبائن بتمرير هذا الرأس دون تنظيف. الوضع الافتراضي يجمع المحاولات بحد مشترك.
حافظ على DB private، وخذ نسخة احتياطية من قاعدة البيانات ومجلد الصور. لا تنشر `.env` ولا كلمات المرور.

## المزايا

- أقسام قابلة للإضافة والتعديل والحذف من لوحة الإدارة.
- منتج مع الاسم والقسم والسعر بالدينار والوصف والصورة والحالة.
- رفع JPEG وPNG وWebP حتى 5MB مع فحص نوع الملف على الخادم.
- سلة مع كميات، بيانات المشتري: الاسم والهاتف والمحافظة/المنطقة والعنوان والملاحظات.
- يحسب الخادم الأسعار من MySQL، ويحفظ الطلب وعناصره داخل transaction.
- تفاصيل الطلب تبقى محفوظة عند حذف المنتج لاحقاً.
- رقم طلب ورسالة واتساب منظمة فيها المنتجات والكميات والأسعار والمجموع والبيانات.
- تسجيل دخول الإدارة بجلِسة HttpOnly لمدة 8 ساعات، CSRF، حدود محاولات، واستعلامات SQL بمعاملات.
- الصفحة العامة لا تعرض منتجات مخفية، وعمليات الإدارة تتطلب تسجيل دخول.

## واتساب

الموقع يجهز رسالة نصية ويفتح واتساب صاحب المحل. **المشتري يجب أن يضغط إرسال داخل واتساب**. ليس إرسالاً تلقائياً عبر WhatsApp Business API. حفظ الطلب لا يؤكد وصول رسالة واتساب. أجور التوصيل والتوفر النهائي يؤكدهما المحل.

## المعاينة

رابط المعاينة المرفق يعرض نفس واجهات Next.js ببيانات تجريبية. هذه البيانات لا تحفظ في MySQL ولا تعد عروض بيع. يمكن تجربة الإدارة بكلمة مرور عشوائية داخل المعاينة فقط؛ النسخة الفعلية تتحقق من ADMIN_PASSWORD. رفع الصور وتجميع الطلبات الفعليان متاحان عند تشغيل النسخة الكاملة.

## التحقق

`npm test` يفحص بيانات الزبون والكمية وتنسيق رسالة واتساب ورفض ملفات مزيفة كصور.
تم التحقق من بناء Next.js. لم يتم إجراء اختبار اتصال MySQL حي في بيئة الإعداد لأنها لا توفر خادماً MySQL أو Docker. يلزم التحقق من `/api/health` بعد التشغيل، ثم تجربة إنشاء قسم، رفع صورة، إضافة منتج، حفظ طلب، ومراجعة تفاصيله من الإدارة.
